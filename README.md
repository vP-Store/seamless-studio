# ✦ Seamless Studio

Dein persönlicher Editor für Instagram **Seamless-Panorama-Carousels** — als PWA, komplett offline-fähig. Alle Fotos bleiben zu 100 % auf deinem Gerät.

## Was die App kann

- **Panorama-Leinwand** mit 2–20 Slides (4:5, 1:1 oder Story 9:16) und Schnittkanten-Anzeige
- **Fotos** hochladen, frei verschieben, drehen, skalieren, spiegeln — mit Maus oder Touch (Zwei-Finger-Gesten)
- **18 Rahmen-Stile**: Polaroid, Herz, Kreis, Bogen, Tape-Ecken, Briefmarke, gerissenes Papier, Filmstreifen u. v. m.
- **12 Filter-Presets** + manuelle Regler (Helligkeit, Kontrast, Wärme, Vignette, Filmkorn …)
- **60+ Hintergründe**: Aquarell-Verläufe in 12 Farbwelten, Texturen, Muster, eigenes Bild, eigener Verlauf
- **50+ Sticker**: Herzen, Funkelsterne, Botanik, Baby-Motive, Linien, Emojis
- **🔒 Privacy-Tools**: deckende Herzen/Sterne/Kreise + Blur- und Pixel-Bereiche für Gesichter
- **Textfelder** mit 10 Schriftarten, frei platzierbar — mit Warnung, wenn Text über einer Schnittkante liegt
- **Auto-Layout**: ordnet alle Fotos mit einem Klick versetzt & gekantelt an, ohne Überlappung
- **Undo/Redo**, Einrasten, Ebenen-Steuerung, Auto-Speichern, Projekt als Datei sichern/laden
- **Export**: nummerierte Slides als ZIP (Standard oder 2K) + Panorama; am Handy direkt teilen
- **Hell/Dunkel-Modus** (◐-Knopf oben rechts)

## 🚀 Auf GitHub veröffentlichen (einmalig, ~5 Minuten)

1. Auf [github.com](https://github.com) einloggen
2. Oben rechts **+** → **New repository**
   - Name: `seamless-studio`
   - **Public** auswählen → **Create repository**
3. Auf der neuen Repo-Seite: **uploading an existing file** anklicken
4. **Alle Dateien und Ordner aus diesem Projektordner** per Drag & Drop hineinziehen
   (wichtig: `index.html` muss direkt im Hauptverzeichnis liegen, ebenso die Ordner `js`, `fonts`, `icons`, `lib`)
5. Unten **Commit changes** klicken
6. Im Repo: **Settings** → linke Leiste **Pages** → unter *Branch* **main** und */ (root)* wählen → **Save**
7. Nach 1–2 Minuten ist die App live unter:
   **`https://DEIN-BENUTZERNAME.github.io/seamless-studio/`**

> Hinweis: Beim Browser-Upload können Ordner per Drag & Drop hochgeladen werden (Ordner aus dem Datei-Explorer direkt ins Upload-Feld ziehen). Falls dein Browser das nicht mitmacht, lade die Ordner nacheinander hoch.

## 📱 Als App installieren

- **iPhone/iPad (Safari):** Seite öffnen → Teilen-Symbol → **„Zum Home-Bildschirm"**
- **Android (Chrome):** Seite öffnen → Menü ⋮ → **„App installieren"**
- **PC (Chrome/Edge):** Installations-Symbol in der Adressleiste anklicken

Nach dem ersten Besuch funktioniert die App **komplett offline**.

## 🔄 Updates einspielen

Neue Version der Dateien einfach wieder ins Repo hochladen (gleicher Weg wie oben, vorhandene Dateien werden ersetzt). Alle Geräte bekommen das Update automatisch beim nächsten Öffnen mit Internet.

## Datenschutz

Seamless Studio hat keinen Server, kein Tracking, keine Cookies. Fotos und Projekte werden ausschließlich lokal im Browser deines Geräts gespeichert und verlassen es nie.
